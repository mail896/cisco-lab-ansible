Vorschau

Zeigt die Aufgaben der Baseline für einen Client, einschließlich optionaler Schritte.

    SSH-Erstaufnahme

    Benötigt eine geprüfte Hardwaredatei auf LAB-Teacher und den ED25519-Fingerabdruck von der Konsole des Zielrechners. Passwortfelder werden nach dem Start geleert.

    ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub

    Basisinstallation starten

    Bereits aufgenommene Clients auswählen. Höchstens zwei werden gleichzeitig installiert. Veyon kann pro Client mit eingerichtet werden.
